# Skybet Customer Page Suite

Skybet will use an original sports match-centre structure designed for mobile-first discovery and desktop comparison. The product will not copy Football.com visual assets, exact layout, page markup, controls, labels, or data. It will instead provide a distinct Skybet page suite with a blue, white, navy, and restrained emerald design system.

| Route | Purpose | Primary controls |
|---|---|---|
| `/` | Sports discovery and match-centre overview | Sport filters, live/upcoming switch, simulated feed cards |
| `/live` | Full live-event board | Event rows, match filters, simulated live status |
| `/sports` | Upcoming sport and competition discovery | Sport tabs, competition cards, event links |
| `/games` | Simulated games-provider feed preview | Feed refresh, category filters, event preview |
| `/event/:id` | Event detail and preview selection context | Market preview, event summary, return navigation |
| `/search` | Searchable demo event catalogue | Keyword field, sport filter, result rows |
| `/activity` | Customer preview activity view | Saved preview selections, account-control shortcuts |
| `/account` | Account controls and safer-play preview | Profile, safety controls, support routes |
| `/admin` | Protected administrative workspace | User search, referral rules, overrides, audit context |

The mobile experience will use a compact header, live-status rail, horizontally scrollable sport filters, focused event cards, and a persistent bottom navigation. Desktop will retain an expanded header and multi-column information layout. All event, market, and game-provider material remains non-transactional preview content.
