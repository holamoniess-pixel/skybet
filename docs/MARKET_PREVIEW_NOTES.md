# SKYBET Preview Market Notes

## Purpose

This note records the information architecture used to expand the **non-transactional SKYBET match preview**. It is not a wagering product specification, does not provide financial advice, and does not enable deposits, wagers, payouts, or reward crediting.

## Adapted preview groups

Football match-result views use a three-outcome presentation: home, draw, and away. Expanded preview groups add total-goals and both-teams-to-score examples. These categories are common reference patterns, while SKYBET’s wording, layout, values, and safe preview behaviour are original.

| Preview group | Example labels | UI treatment |
| --- | --- | --- |
| Match result | Home, Draw, Away | Visible compact row on every card |
| Total goals | Over 2.5, Under 2.5 | Available through the card’s expand control |
| Both teams to score | Yes, No | Available through the card’s expand control |
| Other sports | Winner, total, handicap examples | Adapted to the sport without a draw where inappropriate |

Each selectable value opens the **Preview slip** only. The interface continues to state that it does not accept real-money actions.
